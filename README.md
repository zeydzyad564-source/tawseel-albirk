# توصيل طلبات البرك — Backend

هذا السيرفر مخصص للواجهة الحالية: قاعدة PostgreSQL + Node/Express + JWT + bcrypt.

- العملاء: طلبات غير محدودة، ويرون طلباتهم فقط.
- المندوبون: يرون الطلبات المتاحة، ولا يقبلون أكثر من طلبين نشطين.
- الإدارة: ترى كل الطلبات والمندوبين.
- التوصيل محصور في نطاق البرك (مركز 18.2167, 41.5350، نصف قطر 18 كم) ويتم التحقق على السيرفر.

## التشغيل
1. `npm install`
2. أنشئ `.env` من `.env.example`.
3. أنشئ الجداول: `psql "$DATABASE_URL" -f schema.sql`
4. `npm start`
5. اختبر `/health`.

أو استخدم `docker compose up -d --build`.

مهم: الواجهة المرفقة حالياً تحفظ البيانات في localStorage؛ لذلك بعد تشغيل السيرفر يجب ربط دوال تسجيل الدخول والطلبات والعروض بهذه API حتى تصبح البيانات حقيقية ومشتركة بين الأجهزة.
